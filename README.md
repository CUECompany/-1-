## 🎯 Описание работы

**В рамках работы решаются следующие задачи:**

1. Загрузка и масштабирование данных `load_digits()`

4. Оценка качества метриками ARI, AMI
5. Методы локтя и силуэта для определения оптимального числа кластеров
6. Применение PCA для снижения размерности
7. Визуализация кластеров и их границ

### Часть 2. Датасет Arrhythmia (Вариант 14)
1. Загрузка данных Arrhythmia (279 признаков, 452 объекта)
2. Обработка пропущенных значений
3. Масштабирование признаков
4. PCA до размерности 2 (анализ дисперсии, собственные числа)
5. Кластеризация KMeans++ в PCA-пространстве
6. Оценка качества кластеризации
7. Визуализация результатов

## 💡 Выводы

### По датасету Digits:
1. **KMeans++** показывает наилучшее качество кластеризации среди всех методов инициализации
2. **Метод локтя и силуэта** однозначно указывают на оптимальное число кластеров = 10
3. **PCA** эффективно снижает размерность с 64 до 10 признаков с сохранением ~60% дисперсии
4. Визуализация подтверждает, что кластеры хорошо разделимы в 2D пространстве

### По датасету Arrhythmia:
1. **PCA** с 2 компонентами объясняет лишь ~23% дисперсии, что характерно для высокоразмерных медицинских данных
2. **Качество кластеризации** (ARI ≈ 0.18) ниже, чем на Digits, что обусловлено:
   - Высокой размерностью (279 признаков)
   - Дисбалансом классов
   - Наличием шума и пропусков в данных
   - Сложной внутренней структурой данных
3. **Центры кластеров** корректно отображаются на графиках и находятся внутри своих кластеров
4. **Метод локтя** подтверждает оптимальность выбора 2 кластеров

### Общие выводы:
1. **PCA** является эффективным инструментом для визуализации высокоразмерных данных
2. **KMeans++** - оптимальный выбор для кластеризации по соотношению качество/скорость
3. Качество кластеризации сильно зависит от структуры данных и выбранного пространства признаков
4. Для сложных датасетов рекомендуется комбинировать PCA с другими методами снижения размерности

## 📚 Контрольные вопросы

**1. Для чего предназначен метод главных компонент и какова его основная идея?**
- Снижение размерности данных с минимальной потерей информации
- Идея: поиск новых ортогональных осей (главных компонент) в направлении максимальной дисперсии

**2. Чем специфичны задачи обучения без учителя?**
- Отсутствие размеченных данных
- Нет эталонных ответов для обучения
- Сложность оценки качества

**3. Как можно оценить качество кластеризации?**
- Внешние метрики: ARI, AMI (требуют истинные метки)
- Внутренние метрики: Silhouette, Davies-Bouldin (без истинных меток)

**4. Какова постановка задачи кластеризации?**
- Разбиение множества объектов на группы (кластеры)
- Объекты внутри кластера максимально похожи
- Объекты из разных кластеров максимально различны

**5. Какие алгоритмы подойдут для кольцевидных элементов?**
- DBSCAN (на основе плотности)
- Spectral Clustering
- OPTICS

**6. Какой процент остаточной дисперсии выбрать для выбора n-ного количества главных компонент?**
- Обычно 5-10% (сохраняем 90-95% дисперсии)
- Основывается на правиле "локтя" на графике explained variance

**7. Какова основная идея алгоритма KMeans?**
- Минимизация суммы квадратов расстояний до центров кластеров
- Итеративный процесс: назначение точек -> обновление центров

**8. Какова основная идея агломеративного алгоритма?**
- Иерархическая кластеризация снизу вверх
- Каждый объект - отдельный кластер
- Последовательное объединение ближайших кластеров
